# SkillNotes

Сервис для ведения личных заметок с поддержкой Markdown.

## Функциональность

- Регистрация и аутентификация пользователей
- Создание, просмотр, редактирование заметок
- Архивация и восстановление заметок
- Фильтрация по дате создания
- Постраничная загрузка заметок
- Автоматическое создание демо-заметки для новых пользователей
- Поиск заметок по заголовку
- Вход через GitHub

## Технологии

- Node.js и Express
- MongoDB для хранения данных
- Nunjucks для шаблонизации
- Svelte для клиентской части
- Markdown для форматирования заметок

## Установка и запуск

### Предварительные требования

- MongoDB
